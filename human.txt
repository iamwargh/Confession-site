================================================================

[H-1] ⭐ Create Supabase account + new project

       → Save: Project URL + Anon Key + Service Role Key
       → ⏰ Time: 10 minutes

[H-2] ⭐ Create Vercel account (for deployment)
       → Go to https://vercel.com
       → Sign up with GitHub
       → ⏰ Time: 5 minutes

[H-3] ⭐ Create GitHub repository
       → Go to https://github.com
       → New repo: "confession-site" (private recommended)
       → Clone to your local machine
       → ⏰ Time: 10 minutes

[H-4] Domain name decide karo + purchase

PHASE 2 — ENVIRONMENT SETUP
================================================================

[H-5] Install Node.js (if not installed)
       → Download from https://nodejs.org
       → Use LTS version
       → Verify: node -v and npm -v in terminal
       → ⏰ Time: 5 minutes

[H-6] Set up .env.local file with Supabase keys
       → After AI generates the file template, YOU fill in:
         NEXT_PUBLIC_SUPABASE_URL=your_url_here
         NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key_here
         SUPABASE_SERVICE_ROLE_KEY=your_key_here
       → ⚠️ NEVER share these keys or push to GitHub
       → ⏰ Time: 5 minutes

[H-7] Run Supabase SQL in dashboard
       → After AI generates SQL, go to Supabase Dashboard
       → SQL Editor → paste SQL → Run
       → Verify tables are created
       → ⏰ Time: 15 minutes

       → Enable Email provider
       → Set: Confirm email = ON

[H-14] Configure email templates (optional)
       → Dashboard → Authentication → Email Templates
       → Customize verification & reset password emails
       → ⏰ Time: 15 minutes

[H-15] Set your account as Super Admin
       → After signing up on your own site:
       → Go to Supabase → Table Editor → users/profiles
       → Find your row → change role to 'superadmin'
       → ⏰ Time: 2 minutes

[H-16] Monitor Supabase free tier usage

       → ⏰ Time: ongoing
